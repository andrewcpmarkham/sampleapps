About This Repository

This repository contains a curated selection of sample projects and code created specifically for use in job applications and technical interviews.

The purpose of this repo is to demonstrate:
	•	Code quality and readability
	•	Architecture and design patterns
	•	Real-world problem solving
	•	Platform-specific best practices (e.g. Swift, SwiftUI, MVVM, concurrency, networking, etc.)
	•	Testing, documentation, and maintainability

Each project is intentionally scoped to highlight particular skills or techniques rather than to serve as a full production application. Where relevant, README files inside each project describe the goals, design decisions, and trade-offs.

This repository is actively maintained and evolves as my skills and focus areas develop. 
Additionally, code bases from completed production apps is available for presentation by appointment.
